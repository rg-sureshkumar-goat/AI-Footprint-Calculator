        <p>
          <strong>Per-model AI estimates.</strong> The energy, carbon, and water numbers for each
          prompt come from the open-source <a href="https://ecologits.ai/" target="_blank" rel="noopener">EcoLogits</a>

          each model is (really, how many parameters it uses on each token) and how long the reply
          is, then adds the cost of manufacturing the hardware. The low and high ends are

          right, the Claude numbers on this page are probably too low. The water numbers count
          consumption, not withdrawal: water that is actually gone, evaporated cooling the data
          center or generating its electricity, not water taken in and then returned. Every water
          figure on this page works this way, so the comparisons are apples to apples.
        </p>
        <p>
          <strong>Carbon basis.</strong>
          <a href="https://ecologits.ai/latest/" target="_blank" rel="noopener">EcoLogits</a> gives each

          keep EcoLogits' embodied figure as-is and cost the electricity on the grid where you live,
          using carbon intensities from
          <a href="https://ember-energy.org/latest-insights/global-electricity-review-2024/" target="_blank" rel="noopener">Ember 2024</a>

          roughly 380 (US), 215 (EU), 125 (UK), 580 (China), 700 (India), and 480 (world)
          g CO<sub>2</sub>e/kWh. Water is left on EcoLogits' global basis.
        </p>
        <p>
          <strong>Output, words, and code.</strong> Each row maps to an EcoLogits output-token count:
          tweet (50), short email (170), article summary (250), chatbot reply (400), 5-page report

          read. Only about 15% of its output tokens are treated as actual code; the rest is
          reasoning (which dominates for reasoning models), tool calls, file exploration, and
          explanation, so a 100,000-token session is on the order of 1,500 lines. This is a rough
          estimate with wide uncertainty.

        <p>
          <strong>Your footprint.</strong> "Where you live" is a regional baseline for goods,
          services, and shared infrastructure (per-capita consumption from
          <a href="https://ourworldindata.org/co2-emissions" target="_blank" rel="noopener">Our World in Data</a>);
          home energy and driving are separate so they do not double-count.
          <strong>Home</strong> runs from a small apartment to a big house, about 1.5 to 7 t
          CO<sub>2</sub>e a year (<a href="https://www.eia.gov/consumption/residential/" target="_blank" rel="noopener">EIA RECS</a>;

          <strong>Diet</strong> uses food footprints from
          <a href="https://www.science.org/doi/10.1126/science.aaq0216" target="_blank" rel="noopener">Poore &amp; Nemecek (2018)</a>
          and <a href="https://www.nature.com/articles/s43016-023-00795-w" target="_blank" rel="noopener">Scarborough et al. (2023)</a>:
          about 1.05 t CO<sub>2</sub>e a year for a vegan diet up to 3.2 t for a heavy-meat one.
          <strong>Flying</strong> is anchored to a transatlantic round trip of about 1.6 t
          (<a href="https://iopscience.iop.org/article/10.1088/1748-9326/aa7541" target="_blank" rel="noopener">Wynes &amp; Nicholas 2017</a>);
          the rarely / sometimes / often options are roughly 0.5, 1.5, and 5 such trips a year.
          The <strong>water footprint</strong> uses <strong>blue water only</strong> — freshwater
          actually drawn from rivers, lakes, and aquifers. We deliberately leave out
          <em>green</em> water (rain that falls on farmland and would evaporate anyway, whether or
          not a crop is grown) and <em>grey</em> water (a notional pollution-dilution volume),
          because neither is a real draw on freshwater supplies. The AI figure is already blue
          (data-center cooling and power-plant water), so both sides match. The per-person blue
          footprint is from the
          <a href="https://tools.waterfootprint.org/national-explorer/" target="_blank" rel="noopener">Water Footprint Network (Mekonnen &amp; Hoekstra)</a>:
          about <a href="https://www.mdpi.com/2073-4441/12/11/3286" target="_blank" rel="noopener">450 m<sup>3</sup>/yr for the US</a>
          and <a href="https://www.pnas.org/doi/10.1073/pnas.1109936109" target="_blank" rel="noopener">153 m<sup>3</sup> globally</a>
          (the other regions are scaled by their irrigation intensity and are approximate). Removing
          green water changes the picture a lot: most of a food's water is rain, so a beef burger
          drops from ~1,700 L total to about <a href="https://theconversation.com/heres-how-much-water-it-takes-to-make-a-serving-of-beef-and-why-where-it-comes-from-is-so-important-208155" target="_blank" rel="noopener">6 L of freshwater</a>,
          while irrigated crops stay high.

          <a href="https://www.founderspledge.com/research/climate-and-lifestyle-report" target="_blank" rel="noopener">Founders Pledge Climate &amp; Lifestyle report</a>,
          drawing on
          <a href="https://iopscience.iop.org/article/10.1088/1748-9326/aa7541" target="_blank" rel="noopener">Wynes &amp; Nicholas (2017)</a>
          (living car-free 2.4 t, avoiding a transatlantic flight 1.6 t, hang-drying, recycling, LED
          bulbs) and
          <a href="https://iopscience.iop.org/article/10.1088/1748-9326/ab8589" target="_blank" rel="noopener">Ivanova et al. (2020)</a>
          (green electricity, heat-pump heating, a home retrofit, electric and hybrid cars).
        </p>
        <p>
          <strong>Ways you add emissions (the yearly chart).</strong>
          Manufacturing a new car ≈ 6 t CO<sub>2</sub>e
          (<a href="https://howbadarebananas.com/" target="_blank" rel="noopener">Berners-Lee, How Bad Are Bananas?</a>);
          a <a href="https://www.epa.gov/sites/default/files/2018-02/documents/lca_tv.pdf" target="_blank" rel="noopener">new flat-screen TV ≈ 350 kg</a>;
          a <a href="https://devera.ai/benchmarks/carbon-footprint-of-a-laptop" target="_blank" rel="noopener">new laptop ≈ 250 kg</a>;
          a <a href="https://howbadarebananas.com/" target="_blank" rel="noopener">new bicycle ≈ 100 kg and a new sofa ≈ 90 kg</a>.
          Flights, per passenger
          (<a href="https://co2.myclimate.org/en/flight_calculators/new" target="_blank" rel="noopener">myclimate</a>,
          with a transatlantic round trip ≈ 1.6 t per
          <a href="https://iopscience.iop.org/article/10.1088/1748-9326/aa7541" target="_blank" rel="noopener">Wynes &amp; Nicholas</a>):
          a short-haul round trip ≈ 250 kg, a round-trip US
          cross-country flight ≈ 1 t, and a transatlantic round trip ≈ 1.6 t. A year of average US
          driving (~12,000 mi) ≈ 4.8 t at ~0.40 kg/mile
          (<a href="https://www.epa.gov/greenvehicles/greenhouse-gas-emissions-typical-passenger-vehicle" target="_blank" rel="noopener">EPA</a>).
          A beef burger every week for a year ≈ 156 kg
          (<a href="https://www.science.org/doi/10.1126/science.aaq0216" target="_blank" rel="noopener">Poore &amp; Nemecek</a>, ~3 kg each);
          a <a href="https://theconversation.com/coffee-heres-the-carbon-cost-of-your-daily-cup-and-how-to-make-it-climate-friendly-152629" target="_blank" rel="noopener">year of daily coffee ≈ 77 kg</a>;
          a <a href="https://howbadarebananas.com/" target="_blank" rel="noopener">cotton T-shirt ≈ 7 kg</a>;
          a new smartphone ≈ 70 kg (<a href="https://www.apple.com/environment/" target="_blank" rel="noopener">Apple</a>);
          and a pair of jeans ≈ 33 kg (<a href="https://www.levistrauss.com/wp-content/uploads/2015/03/Full-LCA-Results-Deck-FINAL.pdf" target="_blank" rel="noopener">Levi's</a>).
        </p>
        <p>
          <strong>Everyday things.</strong> A cup of coffee: ~0.21 kg CO<sub>2</sub>e and
          <a href="https://www.weforum.org/stories/2019/03/hidden-water-in-your-cup-of-coffee/" target="_blank" rel="noopener">140 L of water</a>.
          An hour on a <a href="https://www.playstation.com/en-us/legal/ecodesign/" target="_blank" rel="noopener">PS5 (~200 W)</a>;
          3 minutes in a <a href="https://www.siliconvalleypower.com/residents/save-energy/appliance-energy-use-chart" target="_blank" rel="noopener">1,200 W microwave</a>;
          a mile in a gas car (<a href="https://www.epa.gov/greenvehicles/greenhouse-gas-emissions-typical-passenger-vehicle" target="_blank" rel="noopener">EPA, ~0.40 kg</a>);
          a 10-minute hot shower (<a href="https://www.epa.gov/watersense/showerheads" target="_blank" rel="noopener">~21 gal, EPA WaterSense</a>, plus water heating);
          a <a href="https://www.energystar.gov/products/dishwashers" target="_blank" rel="noopener">dishwasher load (≤3.5 gal, ENERGY STAR)</a>;
          a <a href="https://www.energystar.gov/products/clothes_dryers" target="_blank" rel="noopener">dryer load (~3 kWh)</a>;
          <a href="https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1530-9290.2011.00414.x" target="_blank" rel="noopener">printing a 400-page book (~2.7 kg, Wells 2012)</a>
          with <a href="https://waterfootprint.org/resources/Report46-WaterFootprintPaper.pdf" target="_blank" rel="noopener">paper's water footprint</a>;
          a beef burger (~3 kg, <a href="https://www.science.org/doi/10.1126/science.aaq0216" target="_blank" rel="noopener">Poore &amp; Nemecek</a>; ~1,700 L at
          <a href="https://watercalculator.org/footprint/the-hidden-water-in-everyday-products/" target="_blank" rel="noopener">15,400 L/kg beef</a>);
          a <a href="https://www.apple.com/environment/" target="_blank" rel="noopener">new smartphone (~70 kg, Apple)</a>
          needing <a href="https://www.compareandrecycle.co.uk/blog/world-water-week-how-much-water-does-your-smartphone-use" target="_blank" rel="noopener">~12,800 L</a>;
          a <a href="https://www.levistrauss.com/wp-content/uploads/2015/03/Full-LCA-Results-Deck-FINAL.pdf" target="_blank" rel="noopener">pair of jeans (~33 kg, Levi's)</a>
          at ~10,000 L (<a href="https://watercalculator.org/footprint/the-hidden-water-in-everyday-products/" target="_blank" rel="noopener">Water Footprint Network</a>).
        </p>
        <p>
          <strong>How the appliance figures are derived.</strong> The coffee, PS5, microwave, shower,
          dishwasher, and dryer carbon numbers are each that item's measured electricity (cited
          above) times the US grid (~0.38 kg CO<sub>2</sub>/kWh), so they fall on cleaner grids.
          Two depend heavily on assumptions: a cup of coffee is
          <a href="https://theconversation.com/coffee-heres-the-carbon-cost-of-your-daily-cup-and-how-to-make-it-climate-friendly-152629" target="_blank" rel="noopener">~0.05 kg black up to ~0.5 kg for a large latte</a>
          (we use ~0.2 kg), and a 10-minute hot shower is roughly 0.2 kg on a gas water heater up to
          1.5 kg on electric resistance (we use ~0.7 kg). Where a single authority does not exist,
          figures are rounded mid-range estimates from the sources cited, not false precision.
        </p>
        <p>
          <strong>Water comparisons (blue water).</strong> The water charts use the
          <strong>blue</strong> (freshwater) component only, so the comparison items are the
          irrigation- and process-water heavy ones, from the
          <a href="https://watercalculator.org/footprint/the-hidden-water-in-everyday-products/" target="_blank" rel="noopener">Water Footprint Network</a>
          and crop studies: a beef burger (~6 L, since beef is ~90% rainwater), a cup of coffee
          (~4 L), a slice of bread (~8 L), an egg (~15 L), a glass of milk (~22 L), a bowl of rice
          (~25 L), an avocado (~60 L), a handful of almonds (~120 L, as
          <a href="https://www.almonds.org/sites/default/files/2020-05/Water_footprint_plus_almonds.pdf" target="_blank" rel="noopener">each California almond takes ~12 L of irrigation</a>),
          a cotton T-shirt (~1,500 L of its 2,700 L total is blue), a pair of jeans (~5,000 L), and a
          <a href="https://www.compareandrecycle.co.uk/blog/world-water-week-how-much-water-does-your-smartphone-use" target="_blank" rel="noopener">new smartphone</a>
          (mostly ultrapure freshwater). The savings come from cutting irrigated products (a few
          fewer cotton clothes) and outdoor watering: a typical lawn drinks roughly 20,000 gal of
          freshwater a year, so letting it go unwatered or replacing it with native plants saves most
          of that (<a href="https://www.epa.gov/watersense/landscaping-tips" target="_blank" rel="noopener">EPA WaterSense</a>).
          Eating less meat barely moves the blue total, because almost all of meat's water is rain.
          Energy and manufactured goods have a blue-water cost too: thermoelectric power plants
          evaporate about
          <a href="https://www.nrel.gov/docs/fy11osti/50900.pdf" target="_blank" rel="noopener">0.47 gal of freshwater per kWh</a>
          (NREL, cooling/consumption only), so an hour of central air conditioning (~3 kWh) consumes
          roughly 1.4 gal and a day of the
          <a href="https://www.eia.gov/tools/faqs/faq.php?id=97" target="_blank" rel="noopener">average US home's electricity (~29 kWh)</a>
          about 14 gal — the very same power-plant cooling water that makes up much of AI's footprint.
          Printing a 300-page book uses on the order of ~5 gal of process freshwater
          (<a href="https://waterfootprint.org/resources/Report64-WaterFootprint-Paper.pdf" target="_blank" rel="noopener">paper's water footprint</a>
          is mostly rain on trees, with the blue mill water lower since most is returned to rivers).
        </p>

    function bump(row, input, dir) {
      const cur = row.count || 0;
      let step = 1; if (cur >= 50) step = 10; else if (cur >= 20) step = 5;
      let next = cur + dir * step; if (dir < 0 && cur > 0 && cur <= step) next = 0;
      row.count = Math.max(0, Math.min(100000, next)); input.value = String(row.count); updateOutputs();
    }

Three features, each in its own file so the diff is legible:

### 1. Live session tracker — [tracker.js](assets/js/tracker.js)

### 3. Monthly budget, alerts & model swaps — [budget.js](assets/js/budget.js)

Turns the number into a target and a next step.

- Monthly allowance defaulting to the company average, amber at 75%, red at 100%

**The through-line:** the original asks you to describe a typical day and shows what it costs — right for a curious reader, wrong for someone using AI all day at work. Short answer: **not for personal ChatGPT/Claude chat accounts — no API exposes that.** But there are three real automatic paths, and one of them I just confirmed works on your machine.

### What actually exists

| Source | Automatic? | Granularity | Catch |
|---|---|---|---|
| **claude.ai / chatgpt.com personal chat** | ❌ No | — | No usage API at all. Anthropic's docs state plainly: *"The Admin API is unavailable for individual accounts."* Only a manual data export, after the fact. |
| **Anthropic Usage & Cost Admin API** | ✅ Yes | Per **API key / workspace / model**, in **1-minute buckets**, data within ~5 min | Needs an admin key (`sk-ant-admin01-…`). Covers API usage, not chat. Not per-person unless each employee has their own key. |
| **Claude Enterprise Analytics API** | ✅ Yes | Per-user | Requires Claude Enterprise + an Analytics API key. This is the one that covers claude.ai *chat* usage for a company. |
| **Claude Code Analytics API** | ✅ Yes | **Per-user** costs | Anthropic's documented answer for per-person Claude Code breakdowns. |

So the "employees at a company" framing in your brief is exactly the case that *is* solvable — it's individual consumer accounts that aren't.

### The one you can use today, with no credentials

I checked your machine, and Claude Code already writes complete transcripts locally with exact token counts:

```json
model: claude-opus-5
usage: {"input_tokens": 2, "cache_creation_input_tokens": 15969,
        "cache_read_input_tokens": 37111, "output_tokens": 2807, ...}
```

Those live in `~/.claude/projects/**/*.jsonl`. A script could parse them and populate the tracker automatically — no API key, no admin access, no network call. It'd cover your Claude Code usage precisely, though not your chat usage.

### Why the calculator can't call any of these directly

Two hard blockers, both fundamental rather than fixable:

1. **CORS** — browsers refuse cross-origin calls to `api.anthropic.com` from a page on `github.io`.
2. **Credential exposure** — an admin key in client-side JavaScript is readable by anyone who opens devtools. That key can read your whole org's usage and billing. It must never touch the browser.

Any automatic path therefore needs a small server (or a local script) between the API and the page. That's precisely why I built the `AIPF.setTeamData()` hook — it's the seam where real data plugs in.

### One thing that would actually improve accuracy

Worth noting: real data would make the estimates *better*, not just easier. Right now the tracker asks you to pick an output-size bucket (chat ≈ 400 tokens, report ≈ 5,000). Real usage gives exact output-token counts, so I could interpolate against the EcoLogits curve instead of rounding to a bucket.
