# Transcripts

Session transcripts for this project, kept as evidence of process.

- `session-2026-09-12.md` — the build session: porting Andy Masley's calculator
  to a standalone site and adding the three features.
- `debrief-*.md` — Unit 1 debrief conversations, saved separately so debrief
  evidence stays distinct from build sessions.

These are sanitised before being committed: the author's email address, macOS
home path and username, and temporary session paths are replaced. Message
content, tool calls, and results are otherwise unaltered. Each file states at
the top what was redacted.

Tool output in these transcripts is truncated to 400 characters per call to
keep them readable; the complete logs, including screenshots, are kept locally
and are not committed.
